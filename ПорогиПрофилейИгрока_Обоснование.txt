================================================================
ПОРОГИ ПРОФИЛЕЙ ИГРОКА (ProfileService) — ОБОСНОВАНИЕ
================================================================

Файл: backend/Application/Services/MetricAnalytic/ProfileService.cs
Использование: GetSportsmanProfileAsync → BuildProfile → отдаёт
список активных и потенциальных профилей.

----------------------------------------------------------------
ПРИНЦИП КАЛИБРОВКИ
----------------------------------------------------------------

Все пороги откалиброваны по:
  • GPS-литературе (Catapult, Bradley 2009, Bush 2015)
  • Реальной статистике из БД (средние значения метрик)

Берётся «уверенно выше среднего», но НЕ верхний край диапазона —
чтобы профиль был достижим для сильных игроков, но не у каждого
второго (раньше пороги были либо слишком низкие → срабатывали
у всех, либо физически невозможные → не срабатывали никогда).

----------------------------------------------------------------
ФОРМУЛЫ КЛЮЧЕВЫХ ИНДЕКСОВ
----------------------------------------------------------------

defenderIndex = PlayerLoad/TotalDistance + AccelPerSecond + DecelPerSecond
  → высокий = много нагрузки на единицу дистанции + резкие движения

centralMidIndex = DistancePerMinute/100 × 0.5 + HRStability
  → высокий = большой беговой объём + стабильный пульс

defensiveMidIndex = (PlayerLoad / Duration_мин) / 10 + LowIntensityRatio
  → высокий = мощная работа за минуту + много низкоинтенсивных пауз

ExplosiveIndex = (ExplosiveEfforts + Acc + Dec) / Duration_сек
  → частота резких движений в секунду

AerobicLoad = (LowSpeedDistance + ModerateSpeedDistance) / TotalDistance
  → доля «спокойного» бега в общей дистанции

SprintRatio = SprintDistance / TotalDistance
  → доля спринт-дистанции (на скорости >25 км/ч) от общей
