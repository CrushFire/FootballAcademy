# Gender char — важная заметка

## Проблема

В сущностях `Normative`, `Sportsman` поле `Gender` имеет тип `char`.
В сиде (`SeedController.cs`) **ошибочно использовалась кириллическая буква** `'М'` вместо латинской `'M'`.

```csharp
// ❌ плохо — кириллица, фильтр на фронте не работает
Gender = 'М'

// ✅ хорошо — латиница
Gender = 'M'
Gender = 'F'
```

## Как приходит на фронт

`char` из C# сериализуется в JSON как строка. Может прийти в трёх форматах:

| Вариант | Пример | Причина |
|---|---|---|
| Латинская строка | `"M"` | Норма |
| Кириллическая строка | `"М"` | Баг в сиде (исправлен) |
| ASCII-число | `77` | Некоторые версии сериализатора |

## Решение на фронте (защитная нормализация)

```ts
function normalizeGender(g: any): string {
  if (typeof g === 'number') return g === 77 ? 'M' : 'F'
  const s = String(g).trim()
  if (s === 'М' || s === 'м') return 'M'
  if (s === 'Ж' || s === 'ж' || s === 'Ф' || s === 'ф') return 'F'
  return s.toUpperCase()
}
```

Используется в `NormativesPage.vue`.

## Правило

- В сиде и везде где создаётся `Gender` вручную — **только латинские** `'M'` и `'F'`
- На фронте при сравнении всегда прогонять через `normalizeGender()`
