# Position — подсказка для фронта

## Enum значения (что передавать в API)

Поле `position` в запросах создания/обновления спортсмена принимает строку — одно из значений:

```
GK
CB, LB, RB, LWB, RWB
CM, CDM, CAM
LW, RW
ST, CF, SS
```

Поле **необязательное** — можно передать `null`.

---

## Рекомендация для выпадающего меню

Группировать позиции визуально, как в реальном футболе:

```
── Вратарь ──────────────
  GK   — Вратарь

── Защитники ────────────
  CB   — Центральный защитник
  LB   — Левый защитник
  RB   — Правый защитник
  LWB  — Левый латераль
  RWB  — Правый латераль

── Полузащитники ────────
  CM   — Центральный полузащитник
  CDM  — Опорный полузащитник
  CAM  — Атакующий полузащитник

── Вингеры ──────────────
  LW   — Левый вингер
  RW   — Правый вингер

── Нападающие ───────────
  ST   — Центральный нападающий
  CF   — Второй нападающий
  SS   — Оттянутый нападающий
```

---

## Связь с аналитикой

Бэкенд автоматически маппит позицию в группу для расчёта коэффициентов:

| Позиции | Группа аналитики |
|---|---|
| GK | Goalkeeper |
| CB, LB, RB, LWB, RWB | Defender |
| CM, CDM, CAM | Midfielder |
| LW, RW | Winger |
| ST, CF, SS | Forward |

Фронту знать группу не нужно — это внутренняя логика бэкенда.
