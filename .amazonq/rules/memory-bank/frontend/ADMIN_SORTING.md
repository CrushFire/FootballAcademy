# Сортировка на фронте — правило

## Всегда двойная сортировка

На всех admin-страницах со списками сортировка всегда двойная:
1. **Основной параметр** — выбранный пользователем (возраст, рост, вес и т.д.)
2. **Вторичный параметр** — всегда `fio` (имя) по возрастанию

Это обеспечивает стабильный порядок при одинаковых значениях основного параметра.

## Шаблон

```ts
return [...list].sort((a, b) => {
  let res = 0
  if (sortBy.value === 'age')         res = (a.age ?? 0) - (b.age ?? 0)
  else if (sortBy.value === 'height') res = (a.height ?? 0) - (b.height ?? 0)
  // ... другие параметры
  if (res === 0) res = (a.fio ?? '').localeCompare(b.fio ?? '') // вторичная по имени
  return sortDir.value === 'asc' ? res : -res
})
```

## Где применять

Все страницы AdminListLayout с локальной сортировкой:
- SportsmenPage, GroupsPage, TeamsPage и все последующие admin-страницы
