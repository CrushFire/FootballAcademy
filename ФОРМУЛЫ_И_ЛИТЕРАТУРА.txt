================================================================================
ФОРМУЛЫ И БИБЛИОГРАФИЧЕСКИЙ СПИСОК
для выпускной квалификационной работы по теме:
"Информационно-аналитическая система спортивной академии"
================================================================================

ИНСТРУКЦИЯ ДЛЯ AI: пользователь хочет получить готовые формулы для вставки в Word
(через Microsoft Equation / редактор формул) и оформленный библиографический
список по ГОСТ. Формулы даны в трёх форматах:
  1) Human-readable (как читать)
  2) LaTeX (для редактора формул Word: Вставка → Уравнение → ввести как LaTeX)
  3) Word-equation (linear form для прямого ввода в редактор формул Word)

Все формулы нумерованы (Ф-1, Ф-2, …). При вставке в дипломную работу
сохранять сквозную нумерацию.

================================================================================
РАЗДЕЛ 1. ФОРМУЛЫ МОДУЛЯ АНАЛИТИКИ (БАЗОВЫЕ МЕТРИКИ)
================================================================================

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-1. Дистанция в минуту (Distance Per Minute)
──────────────────────────────────────────────────────────────────────────────
ОПИСАНИЕ:
  Базовый показатель темпа бега в единицу времени, индикатор активности
  спортсмена за тренировку или матч (рекомендуется Catapult, Bradley).

ЧИТАЕМАЯ ФОРМА:
  DPM = TotalDistance / (Duration / 60)

LaTeX:
  DPM = \frac{D_{total}}{T / 60}

Word Equation (linear):
  DPM = D_total / (T/60)

ОБОЗНАЧЕНИЯ:
  DPM — дистанция в минуту, м/мин
  D_total — общая дистанция за сессию, м
  T — длительность сессии, с

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-2. Доля спринт-дистанции (Sprint Ratio)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  SprintRatio = SprintDistance / TotalDistance

LaTeX:
  SR = \frac{D_{sprint}}{D_{total}}

Word Equation:
  SR = D_sprint / D_total

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-3. Доля высокоинтенсивного бега (High Speed Ratio)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  HSR = \frac{D_{HS}}{D_{total}}

Word Equation:
  HSR = D_HS / D_total

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-4. Аэробная нагрузка (Aerobic Load)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  AerobicLoad = (LowSpeedDistance + ModerateSpeedDistance) / TotalDistance

LaTeX:
  AL = \frac{D_{low} + D_{mod}}{D_{total}}

Word Equation:
  AL = (D_low + D_mod) / D_total

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-5. Стабильность ЧСС (HR Stability)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  HR_{stab} = \frac{HR_{avg}}{HR_{max}}

Word Equation:
  HR_stab = HR_avg / HR_max

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-6. Доля времени в красной зоне ЧСС (HR Red Percent)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  HR_{red\%} = \frac{T_{HR_{red}}}{T_{total}}

Word Equation:
  HR_red% = T_HR_red / T_total

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-7. Кардиоэффективность (Cardio Efficiency)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  CardioEfficiency = TotalDistance / AverageHeartRate

LaTeX:
  CE = \frac{D_{total}}{HR_{avg}}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-8. Индекс восстановления (Recovery Index)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  RecoveryIndex = TimeInSpeedZone1 / SprintEfforts

LaTeX:
  RI = \frac{T_{zone1}}{N_{sprint}}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-9. Соотношение высокой и низкой интенсивности (HI/LO Ratio)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  HI/LO = \frac{Z_5 + Z_6 + Z_7}{Z_1 + Z_2 + Z_3}

Word Equation:
  HI/LO = (Z5 + Z6 + Z7) / (Z1 + Z2 + Z3)

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-10. Анаэробное соотношение (Anaerobic Ratio)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  AR = \frac{D_{sprint}}{D_{HS}}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-11. Энергоэффективность (Energy Efficiency)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  EE = \frac{D_{total}}{E}

ОБОЗНАЧЕНИЯ:
  E — суммарный расход энергии за сессию, кДж

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-12. Способность повторять спринты (Repeat Sprint Ability, RSA)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  RSA = SprintEfforts × (SprintDistance / TotalDistance)

LaTeX:
  RSA = N_{sprint} \cdot \frac{D_{sprint}}{D_{total}}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-13. Взрывной индекс (Explosive Index)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  ExplosiveIndex = (ExplosiveEfforts + Accelerations + Decelerations) / Duration

LaTeX:
  EI = \frac{N_{exp} + N_{acc} + N_{dec}}{T}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-14. Индекс усталости (Fatigue Index)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  FatigueIndex = PlayerLoad_current / mean(PlayerLoad последних 5 тренировок)

LaTeX:
  FI = \frac{PL_{current}}{\frac{1}{5}\sum_{i=1}^{5} PL_{i}}

Word Equation:
  FI = PL_current / (mean PL за 5 последних сессий)

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-15. Стабильность нагрузки (Consistency)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  Consistency = σ(PlayerLoad последних 5 тренировок)

LaTeX:
  C = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(PL_i - \overline{PL})^2}, \quad N = 5

Word Equation:
  C = StDev(PL_1, PL_2, ..., PL_5)

ОБОЗНАЧЕНИЯ:
  σ — среднеквадратическое отклонение
  PL_i — значение PlayerLoad на i-й сессии

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-16. Острая / хроническая нагрузка (Acute-Chronic Workload Ratio, ACWR)
──────────────────────────────────────────────────────────────────────────────
ЧИТАЕМАЯ ФОРМА:
  ACWR = PlayerLoad_acute / PlayerLoad_chronic

Где acute = средняя нагрузка за последние 7 дней,
chronic = средняя нагрузка за последние 28 дней.

LaTeX:
  ACWR = \frac{\overline{PL}_{7d}}{\overline{PL}_{28d}}

ИНТЕРПРЕТАЦИЯ:
  ACWR < 0.8  — недогрузка (риск детренированности)
  0.8 ≤ ACWR ≤ 1.3 — оптимальная зона
  1.3 < ACWR ≤ 1.5 — повышенный риск травм
  ACWR > 1.5  — критический риск (травматизм × 2–4)

РАЗДЕЛ 2. ФОРМУЛЫ "ПЯТИУГОЛЬНИКА" — КОМПОЗИТНЫЕ ПОКАЗАТЕЛИ
================================================================================

ОБЩАЯ КОНЦЕПЦИЯ:
  5 осей пятиугольника физической подготовленности:
  Speed (Скорость), Power (Мощность), Sprints (Спринт-активность),
  Endurance (Выносливость), Explosive (Взрывная сила).
  Каждая ось рассчитывается как взвешенная сумма базовых GPS-метрик.

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-17. Скорость (Speed)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  Speed_{raw} = 0.40 \cdot v_{max} + 0.30 \cdot v_{avg} + 0.30 \cdot HSR

Word Equation:
  Speed_raw = 0.40·MaxSpeed + 0.30·AvgSpeed + 0.30·HighSpeedRatio

ОБОЗНАЧЕНИЯ:
  v_max — максимальная скорость, км/ч
  v_avg — средняя скорость, км/ч
  HSR — доля высокоинтенсивного бега, доля единицы

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-18. Мощность (Power)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  Power_{raw} = 0.50 \cdot PL + 0.25 \cdot E + 0.25 \cdot MP

Word Equation:
  Power_raw = 0.50·PlayerLoad + 0.25·Energy + 0.25·MetabolicPower

ОБОЗНАЧЕНИЯ:
  PL — PlayerLoad (композитная метрика Catapult), у.е.
  E — суммарный расход энергии, кДж
  MP — средняя метаболическая мощность, Вт/кг

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-19. Спринт-активность (Sprints)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  Sprints_{raw} = 0.50 \cdot SR + 0.30 \cdot N_{sprint/min} + 0.20 \cdot v_{max}

Word Equation:
  Sprints_raw = 0.50·SprintRatio + 0.30·SprintEffortsPerMin + 0.20·MaxSpeed

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-20. Выносливость (Endurance)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  Endurance_{raw} = 0.40 \cdot DPM + 0.30 \cdot AL + 0.20 \cdot HR_{stab} + 0.10 \cdot LIR - 0.10 \cdot HR_{red\%}

Word Equation:
  Endurance_raw = 0.40·DPM + 0.30·AerobicLoad + 0.20·HRStability + 0.10·LowIntensityRatio − 0.10·HRRedPercent

ОБОЗНАЧЕНИЯ:
  LIR — доля времени в зоне низкой интенсивности
  HR_red% — доля времени в красной зоне ЧСС (штрафной коэффициент)

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-21. Взрывная сила (Explosive)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  Explosive_{raw} = 0.40 \cdot N_{exp/min} + 0.30 \cdot a_{max} + 0.30 \cdot \frac{N_{acc} + N_{dec}}{T}

Word Equation:
  Explosive_raw = 0.40·ExplosiveEffortsPerMin + 0.30·MaxAcceleration + 0.30·(AccelerationCount + DecelerationCount)/Duration

ОБОЗНАЧЕНИЯ:
  a_max — пиковое ускорение, м/с²
  N_acc — количество ускорений выше порога
  N_dec — количество замедлений выше порога

РАЗДЕЛ 3. НОРМАЛИЗАЦИЯ ПЯТИУГОЛЬНИКА (ГИБРИДНЫЙ ПОДХОД)
================================================================================

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-22. Скорректированный групповой стандарт
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  adj_G^{(i)} = std_G^{(i)} \cdot w_{pos}^{(i)}

Word Equation:
  adj_G = std_G × w_pos

ОБОЗНАЧЕНИЯ:
  std_G — стандарт по группе (МАХ или AVG среди сверстников)
  w_pos — позиционный коэффициент игрока (см. таблицу 1)
  i — номер оси пятиугольника (1..5)

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-23. Скорректированный абсолютный стандарт
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  adj_A^{(i)} = std_A^{(i)} \cdot w_{pos}^{(i)}

Word Equation:
  adj_A = std_A × w_pos

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-24. Относительный и абсолютный счёт по оси
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  rel^{(i)} = \frac{x^{(i)}}{adj_G^{(i)}}, \quad abs^{(i)} = \frac{x^{(i)}}{adj_A^{(i)}}

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-25. Итоговый счёт по оси пятиугольника
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  score^{(i)} = \mathrm{clamp}\bigl(w_{rel} \cdot rel^{(i)} + w_{abs} \cdot abs^{(i)}, 0, 1\bigr)

Word Equation:
  score_i = Clamp(w_rel·rel_i + w_abs·abs_i, 0, 1)

ВЕСА НОРМАЛИЗАЦИИ (зависят от размера группы N):
  N ≥ 30 : w_rel = 0.80, w_abs = 0.20
  N ≥ 15 : w_rel = 0.70, w_abs = 0.30
  N ≥ 5  : w_rel = 0.50, w_abs = 0.50
  N < 5  : w_rel = 0.20, w_abs = 0.80

ОБОСНОВАНИЕ: при малой выборке (молодая группа) доверие смещается
к абсолютному нормативу; при больших — к относительному (по группе).

  DMIdx = (PL / Duration_min) / 10 + LowIntensityRatio

РАЗДЕЛ 6. МЕДИЦИНСКИЙ МОНИТОРИНГ
================================================================================

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-29. Возрастной порог максимальной ЧСС
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  HR_{max}^{thr}(age) = HR_{base}(age) - age

ТАБЛИЦА БАЗОВЫХ ЗНАЧЕНИЙ HR_base:
  U10  : 210     →  порог 200 уд/мин
  U12  : 210     →  порог 198 уд/мин
  U14  : 208     →  порог 194 уд/мин
  U16  : 206     →  порог 190 уд/мин
  U18  : 204     →  порог 186 уд/мин
  U21  : 202     →  порог 182 уд/мин

──────────────────────────────────────────────────────────────────────────────
ФОРМУЛА Ф-30. Сводный медицинский статус (IsHealthy)
──────────────────────────────────────────────────────────────────────────────
LaTeX:
  IsHealthy = C_{cv} \land C_L \land C_R \land C_{IR} \land C_F \land C_{cons}

Где:
  C_cv  (Cardiovascular) = (HR_max < HR_max_thr) AND (HR_avg < 170)
  C_L   (Load)           = (PL < 600) AND (ACWR < 1.5)
  C_R   (Recovery)       = (T_zone1 > 300 с)
  C_IR  (InjuryRisk)     = (PL < 480) AND (N_acc + N_dec < 180) AND (ACWR < 1.3)
  C_F   (Fatigue)        = (T_HR_red < 480 с) AND (FI = 0 OR FI < 1.3)
  C_cons (Consistency)   = (C = 0 OR C ≤ 25)

ПРИМЕЧАНИЯ ДЛЯ ВСТАВКИ В WORD

1. Как вставить формулу в Word из LaTeX-формы:
   - Вставка → Уравнение → выбрать «Линейное» в режиме ввода
   - Скопировать LaTeX-строку
   - Word автоматически распознает и преобразует в профессиональный вид

2. Шрифт формул: Cambria Math (стандартный для Word Equation)

3. Нумерация формул: правое выравнивание, формат (Ф-NN), где NN —
   сквозная нумерация по работе.

4. Таблицы оформлять стилем «Сетка таблицы (светлая)» с границами 0.5 pt;
   заголовок строки полужирный, по центру.

5. В библиографическом списке использовать «висячий отступ» 1.25 см
   (Главная → Абзац → Специальный → Выступ).

6. При ссылке на источник в тексте указывать номер в квадратных скобках, например:
   «...показатель ACWR характеризует риск травматизма [33]...»
